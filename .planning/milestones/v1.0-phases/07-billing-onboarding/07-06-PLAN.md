
```

```

**Fix 3: No Checkout API**

Fix: Add POST /api/stripe/checkout route.

**Fix 4: No Go-Live Status**

Test call verification doesn't update database.

Fix: Add `is_live` or `go_live` column update in testCallVerification hook.

**Fix 5: Price ID Mapping**

`createCheckoutSession()` requires priceId but no env mapping.

Fix: Add STRIPE_PRICE_IDS env var and use in checkout route.
</context>
