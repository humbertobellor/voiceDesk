| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-10-01 | Elevation of Privilege | PATCH /api/notification-settings | mitigate | contractor_id derived from `getUser()` session; `.eq('contractor_id', contractor.id)` filter; RLS policies enforce same constraint (defense-in-depth per Phase 7 pattern) |
| T-10-02 | Tampering | phone number storage | mitigate | `parsePhoneNumber(input, 'US').format('E.164')` before DB write; invalid format → 422 response; stored value is always E.164 or null |
