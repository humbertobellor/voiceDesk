## Component Specification: Telegram Webhook Card

### Card Container

- **Location**: Inside `NotificationSettingsForm`, positioned after Section 3 (per-contractor Telegram link card) and before Section 4 (Event type toggles)
- **CSS class**: Reuse `cardClass` from existing NotificationSettingsForm
  - Background: `bg-[#1E293B]`
  - Border: `border border-[#334155]`
  - Border radius: `rounded-xl`
  - Padding: `p-6`
  - Max width: `max-w-[480px]`
  - Margin bottom: `mb-4`

### Card Header

- **Layout**: Flexbox row, items-center, gap-2
- **Icon**: Bot icon (lucide-react) or Send icon, color `text-[#64748B]`, size `w-4 h-4`
- **Heading**: "Telegram Bot Webhook", color `text-[#F8FAFC]`, font-semibold, text-sm

### Status Display Row

- **Layout**: Flexbox row, items-center, justify-between, py-3, mb-4
- **Status label (left)**: 
  - Text: "Webhook status"
  - Color: `text-[#94A3B8]`
  - Font size: `text-sm`
- **Status value (right)**:
  - If "Not registered": Text `text-[#94A3B8]` saying "Not registered"
  - If registered: Text `text-[#F8FAFC]` showing truncated URL (max 45 chars, ellipsis overflow), monospace font (optional: `font-mono text-xs`)

### Activation Button

- **Type**: `button` (not submit; standalone action)
- **Action trigger**: Server action `activateTelegramWebhook()`
- **Default state**:
  - Background: `bg-[#F97316]` (accent color)
  - Text: `text-[#0F172A]` (dark on orange)
  - Padding: `px-6 py-2`
  - Border radius: `rounded-lg`
  - Min height: `min-h-[44px]` (mobile touch target)
  - Font: semibold, text-sm
  - Hover: `hover:bg-[#F97316]/90`
  - Transition: `transition-colors`
- **Loading state**:
  - Opacity: `disabled:opacity-50`
  - Cursor: `disabled:cursor-not-allowed`
  - Icon: Loader2 (lucide-react) with `animate-spin`, size `w-4 h-4`
  - Copy: "Activating…" (preserves button width while spinning)
  - Button remains disabled during action
- **After success**:
  - No button state change; the status display updates immediately
  - Button returns to default state (clickable again)

### Error Message Display

- **Trigger**: If server action returns an error string
- **Layout**: Below the button, mt-2
- **Styling**:
  - Color: `text-[#EF4444]`
  - Font size: `text-sm`
  - Role attribute: `role="alert"`
- **Dismissal**: Error persists until:
  1. User clicks the activate button again (cleared on new attempt)
  2. User navigates away and returns
  3. Manual retry via button click

### Interaction Flow

1. **Initial load**: `notifications/page.tsx` calls `bot.api.getWebhookInfo()`, passes `initialWebhookInfo` as prop
2. **Card mounts**: React state initialized with `initialWebhookInfo` (either webhook info object or null)
3. **Display**:
   - If info exists and has a webhook: "Webhook registered: {url}"
   - If info is null or no webhook: "Not registered"
4. **User clicks "Activate Telegram Webhook"**:
   - Button enters loading state (spinner, disabled)
   - Server action called: `activateTelegramWebhook()`
   - Server action validates `TELEGRAM_WEBHOOK_URL` env var exists
   - Server calls `bot.api.setWebhook(url, { secret_token })`
   - On success: returns updated webhook info object
   - On failure: returns error string
5. **After response**:
   - If success: State updates with new webhook info; status display shows registered URL; button returns to normal
   - If error: State unchanged; error message displayed below button; button returns to normal (user can retry)
