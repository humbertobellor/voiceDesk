<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Server Action | activateTelegramWebhook() is called by client; server must re-authenticate and verify contractor ownership before calling Telegram API |
| Server Action → Telegram Bot API | TELEGRAM_WEBHOOK_URL and TELEGRAM_WEBHOOK_SECRET are server-only env vars; never sent to browser |
| Server Component → Client Component | initialWebhookInfo prop contains only public webhook URL — no secrets passed through |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-02-01 | Spoofing | activateTelegramWebhook() server action | mitigate | Action calls createSupabaseServer().auth.getUser() to validate JWT before any Telegram API call; unauthenticated callers receive { ok: false, error: 'Not signed in.' } — ASVS V4.1 |
| T-15-02-02 | Elevation of Privilege | activateTelegramWebhook() contractor lookup | mitigate | Service role client queries contractors WHERE user_id = auth.uid() (from validated JWT); cross-contractor activation is structurally impossible — ASVS V4.2 |
| T-15-02-03 | Denial of Service | setWebhook() called with invalid URL | mitigate | Server action validates TELEGRAM_WEBHOOK_URL is non-empty and starts with 'https://' before calling Telegram API; malformed URL returns { ok: false, error } immediately — ASVS V5.1 |
| T-15-02-04 | Tampering | secret_token omitted from setWebhook() | mitigate | Server action explicitly passes { secret_token: TELEGRAM_WEBHOOK_SECRET } as second argument to bot.api.setWebhook(); validates TELEGRAM_WEBHOOK_SECRET is non-empty before calling; webhook handler at /api/webhooks/telegram enforces secret_token on every incoming update — security config requirement |
| T-15-02-05 | Information Disclosure | TELEGRAM_WEBHOOK_SECRET in server action | mitigate | Secret read only from process.env (server-only); never returned to client; never logged; server action returns only the webhook URL (non-secret) from getWebhookInfo() to the browser |
| T-15-02-06 | Information Disclosure | getBot() exported from telegram.ts | accept | getBot() is server-only module (import 'server-only' at top of file); Next.js tree-shaking prevents client bundle inclusion; only accessible in server action and Server Component contexts |
| T-15-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages in this plan; grammy v1.42.0 already approved in Phase 5 |
</threat_model>
