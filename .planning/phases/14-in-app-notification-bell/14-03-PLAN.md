## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-03-01 | Tampering (IDOR) | mark-all-read contractor_id | mitigate | contractor_id in UPDATE WHERE clause comes from session-derived contractor.id lookup, NOT from request body. A contractor cannot clear another contractor's notifications by passing a different ID in the body — the route ignores the body entirely. |
| T-14-03-02 | Spoofing | mark-all-read unauthenticated | mitigate | getUser() server-side auth check returns 401 for any request without a valid Supabase session cookie. Same pattern as all other PATCH routes in this codebase. |
| T-14-03-03 | Information Disclosure | email_address in Zod schema | mitigate | email_address is validated as z.string().email().nullable() — invalid email strings are rejected at schema parse (400 response). Server-only import prevents this schema from reaching the client bundle. |
| T-14-03-04 | Tampering | email_address injection | mitigate | Supabase parameterized queries prevent SQL injection. Zod schema validates format before any DB write. |
</threat_model>
