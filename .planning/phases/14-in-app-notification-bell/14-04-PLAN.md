## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-04-01 | Information Disclosure | Supabase Realtime cross-tenant | mitigate | useNotificationsSubscription uses filter: `contractor_id=eq.${contractorId}` on the channel. Combined with app_notifications_select_own RLS policy (contractor subquery pattern from Phase 12), cross-tenant Realtime events are blocked at both the subscription filter and the DB row-level. |
| T-14-04-02 | Information Disclosure | useNotifications fetches via anon key | mitigate | app_notifications RLS policy app_notifications_select_own uses `(SELECT id FROM contractors WHERE user_id = auth.uid())` pattern — anon key with session cookie only returns rows for the authenticated contractor. |
| T-14-04-03 | Tampering | Duplicate Realtime subscriptions | mitigate | useNotificationsSubscription is called only inside NotificationBell component. NotificationBell is mounted once in the layout. Duplicate subscriptions would double-count badge increments. Architecture review: Plan 14-05 mounts NotificationBell once in Sidebar only (desktop) or layout (with responsive classes). |
