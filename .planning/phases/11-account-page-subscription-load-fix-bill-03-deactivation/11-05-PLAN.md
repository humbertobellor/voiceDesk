    Replace the current `interface SubscriptionStatus` with:

    ```
      stripe_customer_id?: string | null

      is_active?: boolean
    }
    ```

    **Change 2 — Add loadError state (D-01):**
    Add `const [loadError, setLoadError] = useState(false)` alongside the existing state declarations.

    **Change 3 — Fix loadSubscription to set loadError on non-ok (D-01):**
    Replace the `useEffect` loadSubscription function body:
    ```
    async function loadSubscription() {
      try {
        const res = await fetch('/api/stripe/subscription')
        if (!res.ok) {
          setLoadError(true)
        } else {
          const data = await res.json()
          setSubscription(data)
        }
      } catch {
        setLoadError(true)
      } finally {
        setLoaded(true)
      }
    }
    ```
    Key: when `!res.ok`, set `loadError = true` and do NOT call `setSubscription(data)`. The subscription state stays null. The UI differentiates between null+loadError (load failed) and null+!loadError (no subscription).

    **Change 4 — Remove duplicate loading state block (D-03):**
    Delete lines 132-136 entirely:
    ```
    {!loaded && (
      <div className="text-center py-8 text-[#64748B]">
        Loading subscription details...
      </div>
    )}
    ```
    Keep the inline `'Loading...'` text at line 88 inside the status span. That is the only loading indicator.

    **Change 5 — Add trialing status display (D-02):**
    In the subscription status span (lines 78-89), add `trialing` to the color map:
    - `active` → `text-green-400`
    - `past_due` → `text-yellow-400`
    - `trialing` → `text-indigo-400`
    - other → `text-[#94A3B8]`

    After the status span, add a conditional trial end date line:
    ```
    {loaded && subscription?.subscription_status === 'trialing' && subscription?.trial_ends_at && (
      <p className="text-xs text-[#64748B] mt-1">
        Trial ends{' '}
        {new Date(subscription.trial_ends_at).toLocaleDateString('en-US', {
          year: 'numeric', month: 'long', day: 'numeric',
        })}
      </p>
    )}
    ```

    **Change 6 — Add load error state display (D-01):**
    After the subscription status card `<div>` (after line 92), add:
    ```
    {loaded && loadError && (
      <div className="bg-red-900/20 border border-red-800 rounded-lg p-3 mb-6">
        <p className="text-sm text-red-400">Failed to load subscription details. Please refresh the page.</p>
      </div>
    )}
    ```
    This renders only when loaded=true AND loadError=true (load failed, not "no subscription").

    **Change 7 — Add deactivated banner (D-09):**
