## Color Contract

### 60/30/10 Split

| Role | Percentage | Token | Hex (Light) | Applied To |
|------|-----------|-------|-------------|------------|
| Dominant | 60% | `--bg` | `#FAF6EC` (vellum-50) | Page background, `<html>`, `<body>` |
| Secondary | 30% | `--bg-elevated` / `--bg-sunken` | `#FBF8EE` / `#F3ECD9` | Sidebar, cards, form panels, table rows |
| Accent | 10% | `--accent` | `#1B4E4A` (teal-500) | See reserved-for list below |

### Accent Reserved For

The `--accent` (teal-500) token is reserved ONLY for:
- Primary action buttons (Submit, Save, Connect, Activate)
- Navigation active/selected state (sidebar active item)
- Link text color
- Focus rings on interactive elements
- Badge background on NotificationBell unread count

Accent is NOT used for: section borders, card backgrounds, table headers, decorative
elements, hover backgrounds, or status indicators.

### Semantic Colors

| Role | Token | Hex (Light) | Applied To |
|------|-------|-------------|------------|
| Destructive | `--danger` / `text-danger` | `#A8442B` (brick-500) | Delete actions, error states, danger badges |
| Success | `--success` / `text-success` | `#4E6B3A` (moss-500) | Connected status, successful saves, positive indicators |
| Highlight | `--highlight` / `text-highlight` | `#C7763B` (amber-500) | Warning states, amber indicators |
| Secondary accent | `--accent-2` | `#4E3457` (plum-500) | Reserved — not used in Phase 16 sweep; available for future phases |

### Dark Mode Semantic Remapping

Semantic tokens remap automatically via `@media (prefers-color-scheme: dark)`.
No UI toggle is implemented this phase. See token table above for all dark values.
Token structure supports future `.dark` class toggle without rework (D-07).
