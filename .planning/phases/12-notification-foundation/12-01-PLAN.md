| T-12-01 | Elevation of Privilege | app_notifications RLS | mitigate | Contractor subquery pattern (D-04): `contractor_id IN (SELECT id FROM contractors WHERE user_id = auth.uid())` — prevents cross-tenant notification reads |
| T-12-02 | Tampering | event_type CHECK constraint | mitigate | DB-level CHECK constraint on event_type ('lead', 'emergency', 'payment_failure', 'system') — rejects invalid values at DB layer, not app layer |

| T-12-04 | Tampering | notification_log channel CHECK | mitigate | ALTER TABLE drops old CHECK and adds new one including 'email' — prevents invalid channel values in Inngest email dispatch (Phase 13) |
| T-12-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this plan — migration SQL + type update only; no supply chain risk |
