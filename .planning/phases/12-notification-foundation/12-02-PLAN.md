  <files>src/lib/notifications/email.ts, tests/notifications/email.test.ts</files>
  <behavior>
    - sendEmail({ to, subject, html }) with RESEND_API_KEY + RESEND_FROM_ADDRESS set and Resend returning { data: { id: 'msg_123' }, error: null } → returns { success: true, messageId: 'msg_123' } and calls resend.emails.send with correct params
    - sendEmail(valid params) with Resend returning { data: null, error: { message: 'Invalid email address' } } → returns { success: false, error: 'Invalid email address' }
    - sendEmail(valid params) with Resend throwing Error('Network timeout') → returns { success: false, error: 'Network timeout' }
    - sendEmail(valid params) with RESEND_API_KEY deleted → returns { success: false } and error contains 'Resend credentials not configured' — does NOT call resend.emails.send
    - sendEmail(valid params) with RESEND_FROM_ADDRESS deleted → returns { success: false } and error contains 'Resend credentials not configured' — does NOT call resend.emails.send
  </behavior>
  <implementation>
    Follow the pattern from 12-RESEARCH.md lines 185-231 exactly:
    - import 'server-only' at top
    - import { Resend } from 'resend'
    - Export SendEmailParams interface: { to: string; subject: string; html: string }
    - Export SendEmailResult interface: { success: boolean; messageId?: string; error?: string }
    - sendEmail() reads RESEND_API_KEY and RESEND_FROM_ADDRESS from process.env
    - If either is missing, return { success: false, error: 'Resend credentials not configured (RESEND_API_KEY or RESEND_FROM_ADDRESS missing)' } without instantiating Resend
    - Otherwise: new Resend(apiKey), call resend.emails.send({ from: fromAddress, to, subject, html })
    - If result.error exists, return { success: false, error: result.error.message }
    - If result.data exists, return { success: true, messageId: result.data?.id }
    - Wrap SDK call in try-catch — catch returns { success: false, error: err.message ?? 'Unknown error' }
    - Do NOT add contractorId or callId to the interface — those belong in Phase 13 Inngest context, not the transport layer
